# Python Port Scanner

A lightweight TCP port scanner built in Python.

## Features
- Scan a single host
- Detect open ports
- Custom port range
- Fast scanning
- Banner grabbing (planned)
- Multi-threading (planned)

## Technologies
- Python
- socket
- threading

## Future Improvements
- Service detection
- GUI
- Export results
- OS fingerprinting
- 
## Usage

1. Enter the target IP address.
2. Enter the starting port.
3. Enter the ending port.
4. The scanner checks each TCP port.
5. Displays all open ports.
